# LojaMusical-SQL

## Sobre o projeto

Este é meu primeiro projeto prático de SQL Server, desenvolvido durante meus estudos de bancos de dados relacionais e análise de dados. O projeto consiste na criação de um banco de dados para uma loja de instrumentos musicais, começando pela estruturação e consulta de dados de clientes.

## Tecnologias

- SQL Server Express 2025
- SQL Server Management Studio (SSMS) 22
- T-SQL

## Conceitos praticados

- Criação de banco de dados (`CREATE DATABASE`)
- Criação de tabelas (`CREATE TABLE`)
- Tipos de dados
- Chave primária (`PRIMARY KEY`)
- Inserção de registros (`INSERT INTO`)
- Consultas (`SELECT`)
- Contagem de registros (`COUNT`)
- Organização e documentação de scripts SQL

## Estrutura atual

- `scripts/01_criar_banco.sql`: criação do banco
- `scripts/02_criar_tabela_clientes.sql`: criação da tabela de clientes
- `scripts/03_inserir_clientes.sql`: inserção dos dados de exemplo
- `scripts/04_consultas_iniciais.sql`: consultas iniciais

## Status

Em desenvolvimento. Novos conceitos, tabelas, relacionamentos e consultas serão adicionados conforme avanço nos estudos.
